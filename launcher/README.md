# Переносимая запускалка Codex

Это запуск обычного интерактивного Codex CLI в выбранной папке. Функционала
Supervisor, ожидания лимитов и автоматического продолжения здесь нет.

## Подготовка нового ПК

1. Установите **Codex CLI** по [официальной инструкции](https://developers.openai.com/codex/cli).
   Проверьте в новом терминале `codex --version`.
2. Выполните `codex login` самостоятельно на новом ПК. Вход и доступ к модели
   зависят от вашего аккаунта. Переносить каталог `.codex` с другого ПК не нужно.
3. На Windows для `start-codex.cmd` Python **не нужен**. Для `launch.py` и macOS/Linux
   нужен [Python 3.11+](https://www.python.org/downloads/).

Архив содержит только исходники запускалки: Python, Codex CLI и аккаунт в него
не входят. Для общения с моделью нужен интернет и доступный лимит аккаунта.
Установку, обновления и авторизацию запускалка сама не выполняет.

## Windows

Из ZIP скопируйте **один файл `start-codex.cmd` прямо в корень проекта**.
Другие файлы рядом с ним не нужны. Дважды нажмите `start-codex.cmd` — появится выбор:

- **1 — Новая сессия** (также Enter).
- **2 — Продолжить последнюю сессию этого проекта** без списка истории.
- **0 — Отмена**.

Путь проекта определяется автоматически, без ввода и перетаскивания.
Можно положить отдельную копию этого файла в каждый нужный проект.

Открывается отдельное окно **Windows PowerShell** с заголовком
`Codex | Windows PowerShell` и вашим штатным профилем. Запускалка не задаёт
цвета фона, текста или шрифт. Оформление нового окна определяется хостом
терминала и может отличаться от отдельного ярлыка с собственными настройками.
Исходное окно CMD закрывается. Windows может разместить новое окно в
Windows Terminal, если он выбран системным хостом: оболочкой всё равно
будет `powershell.exe`, а не CMD. Системные настройки терминала не меняются.
Папка может содержать пробелы и кириллицу; Git-репозиторий не обязателен.

Для продолжения последней сессии без меню откройте PowerShell в проекте:

```powershell
.\start-codex.cmd --resume
```

Дополнительно можно передать другой проект: `.\start-codex.cmd "C:\Projects\Мой проект"`.
Если предпочитаете текущий терминал без открытия отдельного окна, используйте
Python-вариант:

```powershell
python launch.py "C:\Projects\Мой проект"
python launch.py "C:\Projects\Мой проект" --resume
```

## macOS и Linux

При установленном Python 3.11+ (`python3`) и Codex CLI:

```sh
sh start.sh "/home/developer/projects/example"
sh start.sh "/home/developer/projects/example" --resume
```

Без аргумента запускалка спросит путь и режим. Linux/macOS-обёртка предоставлена,
но её реальный запуск на этих ОС пока не проверен; Windows проверяется отдельно.

## Поведение и безопасность

- Открывается терминальный интерфейс Codex; история и настройки остаются
  в штатном локальном хранилище Codex на этом ПК.
- По явному выбору пользователя «Продолжить» вызывает `codex resume --last`
  из папки проекта. В установленном CLI 0.162.1 help подтверждает флаги;
  [официальная документация](https://learn.chatgpt.com/docs/developer-commands?surface=cli)
  подтверждает отбор `--last` по текущей папке без `--all`.
  Сессии из других папок и неинтерактивные ходы не включаются флагами запускалки.
  Если Codex не находит подходящую историю, он сам сообщит о результате;
  автоматического повторного запуска или перехода к другому проекту нет.
  Открытие истории не отправляет поручение «продолжай» модели.
- Windows ACL, права чтения и редактирования папки не изменяются.
  Codex получает выбранную папку как рабочий каталог. Доступ внутри Codex
  определяется вашей существующей конфигурацией sandbox и approvals;
  запускалка не предоставляет дополнительных прав и не ограничивает их флагами.
- Sandbox, approvals, модель, hooks и профиль берутся из вашей конфигурации
  Codex. Запускалка не меняет их и не исправляет сломанный sandbox.
  Проверьте настройки Codex на новом ПК перед работой.
- Команда запуска не содержит задания модели. Дальнейший ввод в Codex
  может расходовать лимиты и менять выбранный проект согласно разрешениям.
- Запускалка не собирает логи переписки, не копирует ключи, историю или
  проекты, не подключается к уже работающим процессам и не открывает порты.
- Одновременное редактирование одного проекта несколькими агентами
  контролируйте сами; блокировки workspace в этой запускалке нет.
- Для выхода используйте средства самого Codex. После его завершения
  Windows PowerShell остаётся открытым с командной строкой, чтобы можно было
  прочитать ошибку или продолжить работу. `exit` закрывает PowerShell.

Если Codex не найден, проверьте его установку и откройте новый терминал.
Python нужен только для Python-варианта, а не для двойного клика на Windows.
Запуск от администратора и изменение ExecutionPolicy не нужны.

## Сборка и тесты (для разработчика)

В исходном репозитории:

```powershell
python -m unittest discover -s tests -v
python tools/build_launcher.py
```

Результат: `dist/codex-launcher.zip`. В сборку включаются только четыре файла
из `launcher/`. Все автоматические тесты используют подмену Codex; реальные
модельные ходы не выполняются.
