# Участие в проекте

Спасибо за интерес к Codex Supervisor. Пока разработка на ранней стадии: **не предполагается**, что утилиту уже можно установить и использовать для непрерывной работы.

## Как помочь

- Проверить [быстрый старт](docs/QUICKSTART.md) на чистой Windows-машине и указать, где не хватает объяснений.
- Предложить улучшения [рабочего процесса](docs/WORKFLOW.md), архитектуры, UX и сценариев тестирования.
- Сообщить о воспроизводимых проблемах Codex CLI и совместимости конкретных версий, **без секретов и личных путей**.
- Помочь с тестами, моками, типизированным app-server RPC и безопасной обработкой неизвестных исходов.

## Оформление изменений

1. Сначала Issue с ожидаемым поведением и критериями приёмки.
2. Одна задача — одна небольшая ветка и PR. По возможности отдельно менять документацию и исполняемый код.
3. PR включает объяснение, команды проверок и результаты, не только фразу «тесты прошли».
4. Не добавлять платные/сетевые модели в CI, автоправки системы или изменения безопасности без отдельного обсуждения.
5. Слияние решается поддерживающим проект после ревью. Не рассчитывайте, что открытие PR означает автоматическое принятие.

**Язык обсуждений и документации сейчас русский**; английский текст и переводы приветствуются через отдельные PR с согласованием. Идентификаторы программ и API — как требует протокол.

## Публичные данные

Не публикуйте auth tokens, `~/.codex`, журналы личных бесед, session IDs реальных аккаунтов, клиентские репозитории, копии приватных тестовых архивов. Скриншоты обрезайте и обезличивайте до загрузки.

## Лицензия

В репозитории **пока нет LICENSE**, поэтому открытый доступ на GitHub **не равен** открытой лицензии на модификацию или распространение. Правила участия не заменяют юридическую лицензию. До публичного релиза предлагается выбрать лицензию отдельно (например, MIT или Apache-2.0 после обсуждения); **не добавляйте её самовольно**.
