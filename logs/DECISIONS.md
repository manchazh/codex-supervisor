# Решения

## 2026-10-14 — переносимая запускалка

По новому поручению пользователя приоритет — ZIP с обычным Codex CLI без
функционала Supervisor. Текущая ветка `issue/3-supervisor-mvp` сохраняется.
Существующий mock-прототип не изменяется; запускалка размещена отдельно.

Выбраны Python 3.11+ и стандартная библиотека, CMD для Windows и sh для
Linux/macOS. Архив не включает runtime, Codex, настройки, auth или историю.
Это переносимые исходники с явно указанными требованиями, а не автономная
поставка Codex. Установка и вход остаются действиями пользователя.

Путь передаётся через cwd дочернего процесса; пользовательский текст не
попадает в shell-команду. Используются только новый интерактивный Codex или
`codex resume` с выбором истории. Политики безопасности не переопределяются.
Тесты подменяют Codex; live-испытания запрещены исходным поручением.

По уточнению пользователя Windows-вход открывает обычный Windows PowerShell
со штатным профилем и остаётся в нём после завершения Codex. ExecutionPolicy,
ACL, sandbox и approvals не меняются; это подтверждено отсутствием таких
команд и флагов в запускалке. Реальные разрешения зависят от настройки Codex.

## 2026-10-14 — двойной клик из корня проекта

Пользователь предпочёл файл в корне каждого проекта вместо перетаскивания
и ввода пути. `start.cmd` стал самостоятельным Windows-входом, без Python:
по умолчанию использует собственный каталог и запускает отдельный
`powershell.exe` через `start`. Прежний вызов PowerShell наследовал окно CMD
и его оформление, что воспринималось пользователем как CMD.
Новое окно имеет явный заголовок и синий фон; штатный профиль сохраняется.
Windows Terminal может быть системным хостом, но оболочка — PowerShell.
Права, настройки безопасности и терминала Windows не меняются.
