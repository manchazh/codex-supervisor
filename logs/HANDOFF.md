## 2026-10-14 — переносимая запускалка

Актуальная версия: файл переименован в `start-codex.cmd`. Пользователю нужно
из обновлённого ZIP скопировать только этот файл в корень проекта.
Двойной клик открывает меню: 1/Enter — новая сессия, 2 — последняя сессия
этой папки, 0 — отмена. Продолжение выполняет `codex resume --last` без
`--all`, по новому явному пожеланию пользователя. Принудительные цвета
убраны, настройки доступа сохраняются. CMD в ZIP имеет CRLF.
Свежая проверка: 39 офлайн-тестов прошли. Реальные модельные ходы,
реальное возобновление истории и другие ОС не проверялись.
Справка CLI 0.162.1 и официальная документация подтверждают фильтр cwd.
Ниже сохранена история предыдущих итераций с прежним именем start.cmd.

Последнее исправление: ошибка `LiteralPath NULL` воспроизведена на байтах
архива. CMD с LF терял переменную пути; прежний тест исправлял окончания
строк при записи. Сборщик теперь всегда выдаёт start.cmd с CRLF, тест
сохраняет байты поставки. До исправления три Windows-проверки упали, после
исправления все 35 тестов прошли. ZIP пересобран; локальный start.cmd тоже
имеет CRLF. Пользователю нужно заменить старый start.cmd новым файлом.
Чужой проект, профиль PowerShell и конфигурация Codex не изменялись.

Последнее уточнение: пользователь хочет двойной клик из корня проекта.
Теперь достаточно скопировать туда только `start.cmd`: Python для Windows
не нужен, путь определяется по расположению файла. Открывается отдельное
окно Windows PowerShell с заголовком и синим фоном. `start.cmd --resume`
открывает штатный выбор истории. ZIP обновлён под этот сценарий.
Linux/macOS и Python-вход сохраняют прежние требования.
Свежая проверка: 35 офлайн-тестов прошли; для Windows подтверждены процесс
PowerShell, заголовок, синий фон, cwd проекта, отсутствие Python и флагов
прав, новый диалог, resume и отказ при отсутствии CLI. Регрессионный тест
также запущен на старом CMD-входе и ожидаемо отверг его. Модель не вызывалась.
Исправление фиксируется отдельным локальным коммитом; повторный push не
делается до разрешения ранее обнаруженного расхождения удалённой ветки.

Ветка: `issue/3-supervisor-mvp`. Пользователь запросил отдельный ZIP запуска
Codex в произвольном проекте, пока без Supervisor. Созданы `launcher/`,
сборщик ZIP и офлайн-тесты. Windows-вход открывает привычный PowerShell и
сохраняет его после выхода из Codex. 33 офлайн-теста прошли, включая запуск
распакованного ZIP с фиктивным CLI и проверкой рабочей папки.

Архив: `dist/codex-launcher.zip` (исключён из Git, пересобирается командой
`python tools/build_launcher.py`). Внутри четыре файла, без личных данных.
На новом Windows-ПК нужны Codex CLI и собственная авторизация; Python 3.11+
нужен только для Python-варианта и Linux/macOS.
