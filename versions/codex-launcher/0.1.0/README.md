# Codex Launcher 0.1.0 — архивная версия

**Дата сохранения:** 2026-10-14. **Статус:** сохранена для использования и
восстановления; дальнейшее развитие этой утилиты не планируется.
Это отдельная утилита запуска Codex CLI, без функций Supervisor.
Не смешивать её версию с версиями Codex CLI или демо Supervisor.

## Как использовать

1. Скачайте [codex-launcher-0.1.0.zip](codex-launcher-0.1.0.zip) и распакуйте.
2. Скопируйте **только `start-codex.cmd`** из ZIP в корень нужного проекта.
3. Дважды нажмите файл: **1 / Enter** — новая сессия; **2** — последняя сессия
   этой папки (`codex resume --last`); **0** — отмена.

На Windows нужен установленный Codex CLI и собственная авторизация.
Python для CMD-входа не нужен. Открывается отдельный Windows PowerShell;
цвета не переопределяются. Настройки Codex, Windows ACL и approvals не меняются.
После выхода из Codex PowerShell остаётся открытым.

ZIP содержит четыре файла: `start-codex.cmd`, `launch.py`, `start.sh`,
`README.md`. Последние два способа запуска требуют Python 3.11+;
подробности находятся в README внутри ZIP. Все исходники утилиты сохранены
в самом ZIP, дополнительно исходная реализация доступна в коммите `059d353`.
Компонентный Git-тег этой версии: `codex-launcher-v0.1.0`.

## Проверено и ограничения

- Пользователь подтвердил запуск на Windows и продолжение последней сессии.
- Офлайн-тесты проверяют argv, cwd, меню, отмену, ошибки и байты CMD в ZIP.
  Новые реальные модельные ходы для тестов не запускались.
- `resume --last` без `--all` ограничивается текущей папкой: контракт проверен
  по help Codex CLI 0.162.1 и официальной документации на дату сохранения.
- Linux/macOS-вход предоставлен, но реальный запуск на этих ОС не подтверждён.
- На другом ПК отдельно нужны Codex CLI, аккаунт и интернет для работы модели.
  Совместимость с будущими версиями CLI не гарантируется.
- Нет автоматического восстановления лимитов, Supervisor, установки пакетов,
  переноса аккаунта/истории и блокировки параллельных агентов в одном проекте.

## Целостность

[SHA256SUMS.txt](SHA256SUMS.txt) содержит SHA-256 сохранённого ZIP.
Архив фиксирует именно пользовательскую версию, а не автоматически
пересобирается при дальнейших изменениях `launcher/`.

```powershell
Get-FileHash .\codex-launcher-0.1.0.zip -Algorithm SHA256
```

Сравните результат с SHA256SUMS.txt. Пароли, ключи, конфигурация аккаунта,
реальные проекты и история переписки в архив не включены.
