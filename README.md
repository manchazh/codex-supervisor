# Codex Supervisor

**Привычный Codex в PowerShell + постоянно работающий невидимый Supervisor, который в будущем сможет безопасно продолжать незавершённые задачи после восстановления лимитов.**

## Зачем нужен проект

Работа над сложной задачей не должна требовать особого «ночного режима». Пользователь общается с Codex днём, уходит по своим делам и возвращается к **тому же проекту, истории и результатам**. Будущая утилита должна распознавать подтверждённое исчерпание лимита, ждать достоверного восстановления и безопасно продолжать **только незавершённую работу**, не дублируя команды и не принимая решения за человека.

До появления приложения можно наладить полезную связку из трёх составляющих:

- **ChatGPT** помогает уточнить задачу, оформить GitHub Issue, проверить PR и объяснить результаты.
- **Codex CLI** работает с локальным кодом, запускает проверки и предлагает изменения в своей ветке.
- **GitHub** хранит задачи, обсуждения, коммиты и PR как общую проверяемую историю.

Важно: ChatGPT и Codex — **разные сессии и инструменты**; подключение GitHub к ChatGPT само по себе не запускает Codex на вашем компьютере.

## Быстрый старт

1. Подготовьте Git, Codex CLI и доступ к GitHub по официальным инструкциям. См. [пошаговый старт для Windows](docs/QUICKSTART.md).
2. Создайте собственный Git-репозиторий проекта. В нём заведите `AGENTS.md` с правилами работы.
3. С ChatGPT сформулируйте **одну небольшую GitHub Issue** с целью и критериями приёмки.
4. Запустите Codex в папке проекта и поручите выполнить именно эту Issue **в отдельной ветке**, с тестами и PR.
5. Сравните изменённые файлы, попросите ChatGPT провести ревью, проверьте результат лично. Слияние — только после вашего разрешения.

Подробности и готовые формулировки: [WORKFLOW.md](docs/WORKFLOW.md).

## Будущий Supervisor

**Основной интерфейс — обычный Codex TUI в PowerShell.** Невидимый Supervisor запускается вместе с управляемой сессией и остаётся работающим, пассивно отслеживая состояние задания и структурированные данные о квотах. Если подтверждённый лимит восстановлен и задача действительно не завершена, будущая реализация возобновит точную сессию после проверки безопасности. Не должно быть переключателя «дневной / ночной». Собственный GUI из эксперимента — только запасной вариант.

Ключевые технические ограничения: невозможно работать, когда лимиты исчерпаны, или пока ПК выключен/спит; серверный `reset` и доступность должны подтверждаться, а не угадываться; запросы разрешений нельзя автоматически одобрять ради автономности.

## Безопасность и приватность

**Не публикуйте** токены, ключи, содержимое `~/.codex`, приватную переписку, персональные пути или данные клиентских проектов. Режим полного доступа Codex не является способом исправить сломанную Windows sandbox: он снимает существенную часть ограничений. По умолчанию предпочитайте ограниченный доступ и ручные подтверждения.

Этот репозиторий **публичный**. Issue, PR, комментарии и коммиты тоже доступны посторонним. Перед публикацией обязательно обезличивайте примеры.
